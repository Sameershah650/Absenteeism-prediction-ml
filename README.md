# Absenteeism Prediction System

## Project Overview
This machine learning project predicts employee absenteeism using historical attendance data.

## Features
- Data Cleaning
- Exploratory Data Analysis
- Feature Engineering
- Machine Learning Model
- Performance Evaluation
- Visualizations

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Model Accuracy
Achieved 89% accuracy
